# Agent Note: 界面三步一屏与设计令牌主题

Status: implemented

## Problem

初版界面把功能全量铺开：每个分组标题带一长串括注说明、按钮成排、日志与进度常显、配置文件路径常驻顶部。用户反馈「很啰嗦、体验不好」。需要在保留全部导出能力（连接、勾选库表、排除、导出、日志、取消）的前提下，减少常显控件、突出「连接 → 选表 → 导出」这条主线。

## Decision

主窗口改为「三步一屏」结构，样式集中在 `app/ui/theme.py`：

- **布局**：顶部应用栏（产品名/版本 + 配置下拉 + 配置菜单 + 关于）→ 连接卡片（主机/端口/用户名/密码/眼睛/连接 + 状态徽标）→ 左右分栏（左数据库列表、右表清单，QSplitter 可拖动）→ 底部操作栏（输出目录、浏览、导出设置、预览、开始导出）。
- **渐进披露**：导出设置（时间戳/DROP/中文十六进制/批量）与日志默认折叠；进度只在导出时出现；未连接、未选库时显示居中空态提示而不是空框；配置文件路径不再常显，收进「配置」菜单（含新建/复制/重命名/删除/保存/打开配置目录）。
- **状态与反馈**：连接状态用颜色徽标（灰=未连接、橙=连接中、绿=已连接、红=失败），连接成功后自动加载数据库列表；表清单底部一行统计「表 / 导出 / 仅结构 / 视图」。
- **排除语义可视化**：正则命中的表在清单中锁定为未勾选、灰显并在说明列标注「命中正则（仅结构）」；未勾选=仅结构，勾选=导数据。统计按分类结果计算，而不是按勾选状态估算。
- **令牌化主题**：颜色/间距/圆角/字体来自 `ui-design-system` 生成的设计令牌（主色 `#2563EB`、modern、8pt 间距、8/10px 圆角、微软雅黑 UI），QSS 与 QPainter 图标统一在 `theme.py`；**原生子控件用显式样式覆盖**：运行时在 `%TEMP%\mysql-export-theme` 生成白色对勾与灰色箭头 PNG，供 `QListWidget::indicator`、`QCheckBox::indicator`、`QComboBox::down-arrow` 使用。原因：只给 QComboBox/QCheckBox 设置边框后，Fusion + Windows 主题仍会绘制原生下拉按钮底纹与勾选块（表现为下拉框右侧灰条/蓝线、勾选框变纯蓝方块），必须显式替换子控件才干净。
- **兼容**：核心导出 API 与数据模型不变；`MainWindow` 保留原有属性名与方法名，仅顶部路径标签等 3 处测试断言随结构调整更新。

## Affected repositories

- `mysql-export-data` 分支 `main` commits `d2c45a9`

## Alternatives considered

**仅换配色与字体（不改布局）。** 改动最小、风险最低。不选：用户嫌的是信息密度和组织方式，只换皮解决不了「啰嗦」。

**引入第三方 Qt 主题库（qdarkstyle / QFluentWidgets）。** 现成组件与观感好。不选：新增依赖与分发体积、主题库自带大量控件语义可能与现有 QSS/对话框架冲突，且许可与升级成本不受控。

**深色专业风。** 长时间盯屏更舒适。不选：用户明确选择现代浅色，交付对象是同事日常办公场景。

**向导式多步流程（连接→选库→选表→导出分页）。** 每步更聚焦。不选：导出任务本身只有三步，分页会增加往返点击；保留单页 + 折叠高级项更轻。

**把日志做成独立窗口/抽屉。** 展开时不压缩表格。不选：独立窗口管理成本高；当前折叠 + 限高已够用，且导出结束有报告弹窗兜底。

## Consequences

**收益：** 常显控件从约 30 个降到约 15 个；主线清晰、无操作时界面安静；排除语义在清单上一眼可见（勾选/灰显/原因）；主题令牌集中，后续换色或调间距只改 `theme.py`；截图脚本 `docs/design/capture_ui.py` 可回归视觉。

**代价：** 配置文件路径与保存按钮移入菜单，发现成本略高；日志默认收起，排障时需手动展开；QSS 与 PySide6 版本耦合（6.9.2 验证通过，6.12 在本机有 QtCore DLL 兼容问题）；对勾图标依赖运行时临时文件；顶部路径标签移除导致 3 项旧测试断言调整。

**后续变更：** 自绘主题已在同日被 QFluentWidgets 组件库替换（原因是控件细节维护成本与观感上限），见 `../architecture/2026-11-03-qfluentwidgets-ui-stack.md`；「三步一屏」布局与折叠策略仍沿用本文决定。
